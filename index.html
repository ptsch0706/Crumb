Import Recipe
No API key needed. Use the Claude app or claude.ai to convert a recipe (photo, URL, or text) to JSON, then paste it here.
How To
  1. Tap Copy Prompt below
  2. Open Claude (app or web) and paste it
  3. Then add the recipe — attach a photo, paste a URL, or paste recipe text
  4. Claude will return a JSON block — copy it
  5. Paste it into the field below and tap Import

Shortcut Setup
You only need to do this once. Crumb copies your schedule to the clipboard and opens the Crumb Timers Shortcut, which reads the clipboard and creates iOS reminders for every milestone.
Build the Shortcut
  1. Open the Shortcuts app → tap +
  2. Name it exactly Crumb Timers
  3. Add these actions in order:
1 · Get Clipboard
Reads the JSON Crumb just copied.
2 · Get Dictionary from Input
Parses the clipboard text into a dictionary.
3 · Get Dictionary Value
Key: milestones
4 · Repeat with Each
Iterates over the milestones list. The next actions go inside this block.
5 · Get Dictionary Value
Key: title · Dictionary: Repeat Item
6 · Get Dictionary Value
Key: time · Dictionary: Repeat Item
7 · Get Dictionary Value
Key: note · Dictionary: Repeat Item
8 · Add New Reminder
Reminder: title value
List: any (e.g. Bread)
Alert → At a Time → time value
Notes: note value
If reminders don't appear, make sure you don't have a leftover Text action at the top of the Shortcut — it would override the clipboard.
