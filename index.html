About Sync

Crumb syncs through Firebase. Data is stored under your sync code only — no account or sign-in needed. Anyone with your sync code can read and write your data, so treat it like a password.

Delete All Data
Danger Zone

Deletes all recipes, bakes, categories, and active bakes — locally AND on Firebase if sync is enabled. Cannot be undone. Other connected devices may push their data back if they're still online — disconnect them first for a clean wipe.
